# Hero Carousel Images

Place your hero carousel images in this directory. The carousel expects the following images:

1. `community.jpg` - Image representing community engagement and togetherness
2. `family.jpg` - Image representing families and youth support
3. `culture.jpg` - Image representing cultural celebration and heritage

## Image Specifications

- **Recommended size**: 1920x1080px (16:9 aspect ratio)
- **Format**: JPG or PNG
- **File size**: Optimize for web (under 500KB per image recommended)
- **Content**: Images should work well with text overlays and the Pan-African color gradient overlay

## Current Status

The carousel is currently using placeholder gradients. Once you add images to this directory, update `components/HeroCarousel.tsx` to uncomment the Image component code.
